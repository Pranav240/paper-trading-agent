The finding

Every backtest longer than a single quarter underperformed buy-and-hold, by $39 to $225 on a 20-share basis. The out-of-sample run — executed once, with nothing changed after seeing the in-sample result — lost $63 in a market that was essentially flat.

The project’s founding rule was that an honestly evaluated failure is the correct thing to report. So it is reported, and the machinery built to establish it is the actual deliverable.

What it is

Four nodes, split by whether judgment is required

A Technical Analyst computes RSI-14 and SMA-20 in plain Python — arithmetic is not worth a language model. A Sentiment Analyst reads headlines through GPT-4o-mini. A Portfolio Manager on GPT-4o synthesises both into a proposal. A rule-based Risk Manager holds final authority and can veto or scale any trade.

That last split — propose versus gate — turned out to be the most valuable structural decision in the project. Because the risk layer is code and every input it consumed is stored, alternative risk rules could later be replayed against recorded decisions for free.

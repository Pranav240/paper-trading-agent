Build sequence · paper trading only

V1 first, V2 only if V1 earns it

Six phases build the daily decision-support agent (V1). Six more extend it into a continuous intraday system (V2) — each one reusing or upgrading a specific V1 component, not starting over. Status as of 9 Sep 2026: five of the six V1 phases are settled, and the honest-backtest gate that stands between V1 and V2 has been reached and answered.

Every block here either upgrades a numbered V1 block or is explicitly new — nothing is rebuilt from scratch. None of it is started.

The gate before phase 07 has been reached, and the answer is no. The rule set at the start was: back-test the V1 strategy logic honestly first, because if it shows no real edge on historical data with realistic slippage, running it continuously in V2 won't create one — it will replay the same non-edge faster and with more moving parts to debug.

Seven real-LLM runs on AAPL, 5bps slippage, mark-to-market, each against buy-and-hold over its own window:

#4  in-sample, 13 months−$39
#6  out-of-sample, 6 months−$65
#7, #8  sentiment ablated−$41, −$74
#9  replicate of #4−$130
#14  continuous score node−$225
#3  pilot quarter, 4 trades+$22

Every run longer than a quarter underperformed. The single exception is a 3-month pilot with four closed trades, which beat the baseline mainly because AAPL fell over that window — buy-and-hold lost money and a largely idle system did not. The out-of-sample run was executed once, with no code, prompt or parameter changes made after seeing the in-sample result, which is what makes it worth believing.

So V2 is on hold, and that is the roadmap working as designed. The gate existed precisely to catch this before six more phases were built on top of it. Phase 06 remains worth finishing — deployment is a real skill to demonstrate, and it does not depend on the strategy being profitable.

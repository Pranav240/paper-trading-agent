Build sequence · paper trading only

V1 first. V2 doesn’t need an edge. V4 does.

Six phases build the daily decision-support agent (V1). Four more replace its rule-based risk gate with real risk math and an agent that explains its own alerts (V2) — this doesn’t require V1 to have found an edge, only to exist. Six further phases would turn it into a continuous intraday system (V4), and that one stays gated: it only starts if V1’s strategy logic backtests with a real edge. Status as of 28 Sep 2026: all six V1 phases are settled, the honest-backtest gate has been reached and answered — no edge on this evidence — so V4 stays on hold. V2 does not depend on that gate and is next. V3 — a pivot to Indian markets — is a separate, parallel track driven by data sourcing rather than build phases, and isn’t diagrammed here. See the homepage.

None of this depends on the strategy having an edge — it makes the existing system's judgment better and its reasoning visible. None of it is started.

Every block here either upgrades a numbered V1 or V2 block, or is explicitly new — nothing is rebuilt from scratch. None of it is started.

V2 does not wait on the gate below. It was tempting to lump "improve the risk logic" in with the rest of the on-hold work, but the reasoning doesn't hold up: a better risk model and an agent that can explain its own alerts make the existing V1 system more trustworthy regardless of whether the strategy ever finds an edge. That's a different claim from "run it faster and more often," which is what the gate below is actually about.

The gate before phase 11 has been reached, and the answer is no. The rule set at the start was: back-test the V1 strategy logic honestly first, because if it shows no real edge on historical data with realistic slippage, running it continuously in V4 won't create one — it will replay the same non-edge faster and with more moving parts to debug.

Seven real-LLM runs on AAPL, 5bps slippage, mark-to-market, each against buy-and-hold over its own window:

#4  in-sample, 13 months−$39
#6  out-of-sample, 6 months−$65
#7, #8  sentiment ablated−$41, −$74
#9  replicate of #4−$130
#14  continuous score node−$225
#3  pilot quarter, 4 trades+$22

Every run longer than a quarter underperformed. The single exception is a 3-month pilot with four closed trades, which beat the baseline mainly because AAPL fell over that window — buy-and-hold lost money and a largely idle system did not. The out-of-sample run was executed once, with no code, prompt or parameter changes made after seeing the in-sample result, which is what makes it worth believing.

So V4 is on hold, and that is the roadmap working as designed. The gate existed precisely to catch this before six more phases were built on top of it. Phase 06 was finished anyway — deployment is a real skill to demonstrate, and it does not depend on the strategy being profitable. V2 and V3 (see the homepage) proceed independently of this gate.

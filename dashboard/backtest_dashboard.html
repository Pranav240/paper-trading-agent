Reading this honestly

  • The verdict is negative, and that is the finding. Every run longer than a quarter underperformed buy-and-hold, by $39 to $225. The one exception, run #3, is a 3-month pilot with 4 closed trades that beat the baseline mainly because AAPL fell over that window — buy-and-hold lost money and a largely idle system did not. This project's stated rule is that an honestly evaluated failure is the correct thing to report, so it is reported.
  • A baseline error, found and corrected 2026-09-09. Backtest 4 ran 2022-06-01 to 2023-06-30; runs 7, 8, 9 and 14 ran 2022-06-03 to 2023-06-30. AAPL fell 148.73 to 145.39 across those two extra days, moving buy-and-hold by $66.80 on a 20-share basis. Earlier writeups compared the ablation runs against backtest 4's +$903.80 and concluded they "matched buy and hold"; against their own window's +$970.60 they were $41–74 below it. Every row in the comparison table above uses its own window's baseline.
  • Runs 7 and 8 are ablations. The Sentiment Analyst is replaced by a fixed neutral stand-in while the Portfolio Manager keeps making real LLM calls, so the graph structure is held constant and only the node's content is removed. They outperformed the runs that kept the node — which is what prompted rewriting it.
  • Run 14 changed two things at once — the sentiment node and the Portfolio Manager prompt that reads it. Its heavy trading may come from either. One further ablation separates them; it hasn't been run.
  • Backtests #1 and #2 aren't shown. #1 ran before a transaction bug was fixed (position cap never engaged — 25 buys against a 20-share limit). #2 landed entirely inside a gap in the FNSPID headline data (Jan–Mar 2022), so the Sentiment Analyst never saw a single headline — it wasn't a real test of the two-agent system.
  • "Buy & hold, 20 sh" is what simply buying the position cap on day one and holding to the last day of the window would have made — the honest baseline, not a strawman.
  • Win rate is realized trades only. An open lot at window end isn't included until it closes, which can flatter or understate the picture — see the mark-to-market note above the P&L chart where it applies.
  • Slippage: 5bps against decision price, both directions. Commission: $0 (matches Alpaca). No benchmark beyond buy-and-hold is computed here.

Paper Trading Agent

A static demo of recorded decisions. A four-node agent proposed paper trades on AAPL in backtests; a rule-based risk gate set what actually traded; every decision was stored with its reasoning trace. This site lets you read that record. It does not run anything.

What this is not. Not a live system, not a product, and not evidence of a trading edge: no edge has been established. Paper trading only, never real money. There is no live model behind this site, no login, and nothing to submit. It is a read-only copy of a database snapshot.

How a decision is made

The split between a proposing model and a gating rule is what made the analysis possible: because the Risk Manager is code and every input it saw is stored, other rules can be replayed over the recorded decisions at no cost. Details in the project record.

Recorded results

Each row is the VaR node's own recorded decisions, marked to market on a 20-share cap, against buying and holding 20 shares over the same window. The V1-rules column is a replay of the same decisions under the older rules: a comparison, not a second run.
